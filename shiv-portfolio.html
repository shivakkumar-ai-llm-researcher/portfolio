01

Org-SLM — a pruned model with twelve trades

Derived a 12-layer, 795M-parameter model from Qwen2.5-Coder-1.5B via stride sampling, then trained twelve domain-specific LoRA adapters — React, React Native, Flutter, FastAPI, Java Spring Boot, .NET, and more — each mergeable into a standalone checkpoint.

Wrapped it in a FastAPI backend and an Electron client with local RAG, built for 8GB RAM / 2GB VRAM hardware using a QLoRA 4-bit strategy.

02

voice-nav-slm — voice navigation that understands the tenant

A custom transformer encoder for in-app voice navigation across Firstclick HRMS and SalesPro CRM, exported to ONNX for on-device inference.

Built for tenant-aware dynamic schemas and regional coverage — Tamil, Indian-accented English, and Arabic for the KSA market — conditioned on deep app-state context.

03

slm — an agentic coding CLI, built to run anywhere

A cross-platform CLI inspired by Claude Code and Codex CLI, with eight tools, hardened subprocess handling, and a JSONL session logger for full traceability.

Supports local inference through Ollama (qwen2.5-coder) or OpenAI, and ships as a packaged Windows binary via PyInstaller.

04

Hot Lead Finder — B2B signal intelligence for two markets

A Django/Celery/Redis platform that pulls 35+ signal sources, enriches contacts, and generates pitches through the Claude API with Groq as fallback.

Solved market-specific problems along the way — Arabic encoding, CR-number identity resolution, Etimad auth-gating, and Hijri date handling for the Saudi pipeline.
